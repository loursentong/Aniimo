Ajustements selon le contenu
  • RUPTURE forte : Fulmi · Danzard · Voltignasse · Luminelle
  • Burst Foudre / support élémentaire : Luminelle peut remplacer Turbulaine selon la rencontre

Fulmi
DPS principal
SÛR		 Prismana par défaut ; Base si la pression Ténèbres rend le double type dangereux Lame foudroyante améliorée + Tempête de lames foudroyantes Croc féroce L15 + pacte Fulmi ATQ 20 → REGEN 20 → survie E + N Relâcher Tempête sur un multiple de 3 entailles. Le Pendentif reste une variante neutre, pas le BiS spécialisé actuel.
Danzard
Support CRIT Foudre
SÛR		 Base Balayage tonitruant + Décharge électrique Croc féroce L15 ATQ jusqu’au cap 35 % CRIT Foudre au tooltip ; sinon ATQ 20 → PV E + S Balayage en premier après entrée pour profiter de la compétence gratuite. Pacte Danzard = faible priorité.
Pulsato
REGEN / baisse RÉS Foudre
SÛR		 Base Geyser chargé + Courant perturbateur Plume vive L15 + pacte Pulsato REGEN jusqu’à Geyser 1,20 PE/s ET ultime −42 % RÉS Foudre ; puis survie I jusqu’aux caps Le gros intérêt est la génération PE immédiate + la baisse de résistance Foudre.
Turbulaine
Amplification générale
À TESTER		 Adapter au matchup ; ne pas figer une forme unique Déflagration de Cumulaine + Bouclier nuage Cloche L15 + pacte (plafond DPS) / Carapace L15 + pacte (sûr) PV → défense adaptée au boss Faible priorité Embrumé prêt → Déflagration → sortie immédiate. Cloche à valider sur compétence ramenée à 0 PE.
1
Ouverture

Pulsato ultime si prêt → Turbulaine Déflagration → Danzard Balayage + Décharge → Pulsato Geyser → Fulmi buff CRIT

2
Pré-BREAK

Préparer les buffs avant de déclencher la RUPTURE si la rencontre l’exige.

3
BREAK

Déclencher BREAK puis Fulmi immédiatement ; aucune maintenance support pendant la fenêtre ×250 %.

4
Maintenance

Rafraîchir uniquement les buffs réellement expirés ; laisser les CD tourner hors terrain.

À ne pas oublier

  • Cloche Turbulaine : proc sur compétence ramenée à 0 PE encore à valider avant dépense rare.
  • Les cinématiques d’ultime consomment le chrono : ne pas lancer un ultime de support sans gain réel.

Ténèbres

Stellaria · Fragrancier · Sorcelonde · Casquillon
Composition optimisée de référence — DPS Ténèbres + RUPTURE

↑ Sommaire
Ajustements selon le contenu
  • Sans besoin de breaker : Stellaria · Fragrancier · Sorcelonde · Turbulaine Prismana
  • Couverture Lumière : breaker alternatif selon la rencontre si Casquillon devient trop exposé
Aniimo / rôleFormeCompétences Objet / pacteStatsPersonnalitéNote pratique
Stellaria
DPS principal
SÛR		 Prismana si la couverture Glace est utile ; Base sinon Magie d’ombre + Étoiles filantes Épingles de fission L15 + pacte Stellaria ATQ 20 → REGEN 20 E + S Clone + attaques de base = cœur du DPS. Les Épingles sur clone restent une interaction communautaire à garder sous surveillance.
Fragrancier
Amplification Ténèbres
SÛR		 Base Marquage de parfum + Floraison fanée Croc féroce L15 + pacte Fragrancier ATQ 20 → PV 20 → défense E prioritaire Marquage renforce directement les attaques de base Ténèbres. Viser les caps du tooltip sur baisse RÉS / ultime.
Sorcelonde
REGEN / utilitaire
SÛR		 Prismana actuelle Explosion sonique euphorique + Domaine du trou noir Plume vive L15 + pacte Sorcelonde REGEN 20 → PV I jusqu’au cap Malédiction + attaques de base Ténèbres = récupération PE. Anti-soin / anti-bouclier = variantes de rencontre.
Casquillon
Breaker
SÛR		 Base par défaut Fronde bondissante + Heurt brise-garde Pince gargantuesque L15 RUPTURE 20 → DEF.P 20 E + S + T DEF.P augmente aussi la RUPTURE via le trait. Préparer la jauge à ~99 %, puis déclencher BREAK sur commande.
1
Ouverture

Casquillon pose Fronde et prépare la jauge → Fragrancier ultime si prêt + Marquage → Sorcelonde Explosion sonique

2
Pré-BREAK

Ramener la jauge juste avant le seuil ; Stellaria doit être prête à entrer immédiatement.

3
BREAK

Casquillon déclenche BREAK → Stellaria Magie d’ombre → Étoiles filantes → chaînes d’attaques de base.

4
Maintenance

Rafraîchir Marquage / Malédiction seulement quand nécessaire ou lors d’un changement de cible.

À ne pas oublier

  • Rang15 de la Pince : ne pas compter le doublement comme garanti tant que la condition « potentiel acquis >15 » n’est pas vérifiée.
  • Si la cible change, les debuffs et marques doivent être reconstruits.

Ajustements selon le contenu
  • RUPTURE rapide : remplacer Turbulaine par Casquillon
  • RUPTURE Plante / couverture Feu : remplacer Turbulaine par Nutrion Montagnes
  • Carry de couverture : Rapiéronce contre les counters naturels si nécessaire

Lumiris
DPS principal
SÛR		 Prismana Ombre de Lumiris + Tourbillon de fleurs Plume arc-en-ciel florale L15 ATQ 20 → REGEN 20 E + N Noyau : 2 clones ; ultime : 3e clone. L’objet signature est l’investissement central du carry.
Méliflore
Support CRIT Plante
SÛR		 Prismana si purification utile ; sinon forme selon rencontre Bénédiction épineuse + Rose de soin / Roses destructrices Plume vive L15 ATQ 20 → survie E prioritaire La Plume ferme le trou de Bénédiction : 18 s → 14,4 s pour 15 s de durée live.
Voilotus
REGEN Plante
SÛR		 Base Floraisons de vitalité + Cyclone de feuilles Plume vive L15 + noyau amélioré REGEN 20 → PV 20 I + J Floraisons alimente PE/PU et prépare le terrain Plante.
Turbulaine
Amplification générale
À TESTER		 Adapter au matchup Déflagration de Cumulaine + Bouclier nuage Cloche L15 + pacte (DPS) / Carapace L15 + pacte (sûr) PV → défenses Faible priorité Le support n’a pas besoin d’être Plante : il doit maximiser le carry. Entrée très courte.
1
Ouverture

Turbulaine Déflagration → Méliflore ultime si prêt + Bénédiction → Voilotus ultime si prêt + Cyclone + Floraisons

2
Pré-BREAK

Si variante breaker : préparer la jauge avant de poser le setup final Lumiris.

3
BREAK

Déclencher BREAK → Lumiris Ombre renforcée → ultime si prêt → Tourbillon → chaînes d’attaques de base.

4
Maintenance

Ne pas réinviter les supports pendant BREAK ; reconstruire seulement ce qui expire.

À ne pas oublier

  • Pacte Méliflore : ne pas investir uniquement sur l’ancienne durée 21 s, non confirmée live.
  • Les clones persistants gardent beaucoup de valeur hors terrain : ne pas les réinitialiser inutilement.

Hurlebrasier
DPS principal / burst
À TESTER		 Feu pur vs Plante ; Hautes Plaines Feu/Roche vs Glace Poing enflammé + Coup de pied ardent Croc L15 (sûr) / Gants explosifs L15 si snapshot PE confirmé ATQ 20 → REGEN 20 E + S Vitti +10 PE max ajoute directement une tranche de +30 % à Burn Breaker chargé.
Sparkelf
Amplification Feu
SÛR		 Prismana Parfait si acquis Inspiration + Don de friandise / Énergie étincelante Croc L15 tant que l’ATQ améliore encore les buffs ATQ jusqu’aux caps → PV / REGEN E prioritaire Entrer avec >40 PE. Ultime puis Inspiration juste avant le burst.
Vitti
REGEN / +PE max
SÛR		 Prismana Onde lumineuse éthérée + Spores hypnotiques Plume vive L15 REGEN 20 → PV 20 I Support hors élément mais parfaitement cohérent avec Hurlebrasier grâce au +10 PE max.
Inferlupin
Breaker
SÛR		 Base / Prismana Esprit de Jappardent inébranlable + Rayons croisés Pince gargantuesque L15 RUPTURE 20 → ATQ 20 → REGEN RUPTURE / survie Préparer la jauge puis sortir vite. La fenêtre BREAK observée peut être très courte (~2 s sur certaines cibles).
1
Ouverture

Vitti Onde → Inferlupin prépare la jauge → Hurlebrasier Fire Kick sur vraie esquive → Sparkelf ultime + Inspiration

2
Pré-BREAK

Hurlebrasier doit être prêt et chargé avant de provoquer le BREAK.

3
BREAK

Inferlupin déclenche BREAK → Hurlebrasier Burn Breaker immédiatement.

4
Maintenance

Après le burst : Vitti Butterfly Dance → reconstruire PE → nouveau cycle.

À ne pas oublier

  • Gants explosifs : snapshot PE de Burn Breaker encore non arbitré.
  • Une cinématique d’ultime consomme le timer : n’utiliser les ultimes de support que si leur valeur couvre ce coût.

Breaker
SÛR		 Base Hydroulade + Bouclier aquatique Pince gargantuesque L15 RUPTURE 20 → PV 20 → défense ESTJ Choisir sexe opposé à Ondeloutre pour garantir Attrait. Préparer la jauge et garder les flaques pour Astrophel.

2

4
Maintenance

À ne pas oublier

  • Charme radieux d’Ondeloutre sur Astrophel asexué : interaction communautaire, non validée par notre client.
  • Debuffs liés à une cible doivent être réappliqués si l’adversaire change.

Turbulaine
Amplification générale
À TESTER		 Prismana vs Ténèbres ; Base/Brumes vs Vent Déflagration de Cumulaine + Bouclier nuage Cloche L15 + pacte (DPS) / Carapace L15 + pacte (sûr) PV → défenses Faible priorité Le choix de forme est défensif ; le buff reste général et profite directement à Lunara.

REGEN

Casquillon / Tubabec
Breaker selon cible
SÛR		 Casquillon Base vs Ténèbres ; Tubabec Base vs Vent CQ : Fronde + Heurt / TB : Garde tempétueuse + Souffle de pause Pince gargantuesque L15 CQ : RUPTURE20 → DEF.P20 / TB : RUPTURE20 → PV20 Survie / RUPTURE Le breaker est choisi pour survivre au matchup et déclencher BREAK sur commande.

Ouverture

Breaker prépare la jauge → Turbulaine Déflagration → Vitti Onde → Lunara Éclairs + 4 basics

2
Pré-BREAK

3
BREAK

Breaker déclenche BREAK → Lunara ultime si rentable → 4 basics → Impact → 4 basics.

4
Maintenance

Respecter la boucle skill → 4 attaques de base ; ne pas spammer les compétences.

À ne pas oublier

  • Épingles Lunara : ne pas pacter tant que l’interaction avec le +100 % des Marques n’est pas prouvée.
  • Le coût d’une cinématique d’ultime doit être pris en compte dans les combats chronométrés.
Combat réel : préparer les buffs et la jauge avant BREAK, déclencher BREAK sur commande, puis donner immédiatement le terrain au carry. Les cooldowns progressent hors terrain et les cinématiques d’ultime consomment le chrono.
